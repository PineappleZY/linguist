Linguist 8.2.0 for Windows

安装
1. 双击 Linguist-8.2.0-Setup.exe。
2. 选择安装位置；安装器会创建桌面和开始菜单快捷方式。
3. 从快捷方式打开 Linguist，在 Profile / 个人中填入自己的 DeepSeek API Key。

说明
- 安装包为 Windows x64 桌面程序，应用界面和 PDF 工具均随程序离线内置。
- 查词需要联网，并使用使用者自己的 DeepSeek API Key。
- 未进行商业代码签名；Windows SmartScreen 首次可能提示未知发布者。
  如确认文件来源与 SHA-256 校验值无误，可选择“更多信息”后继续安装。
- 卸载时默认保留个人数据；如需彻底清除，请另行删除 Electron 用户数据目录。
