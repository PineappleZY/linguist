# Radicle 5.0 — 评审清单与自审

这份文件是 5.0 的交付物之一：把那份外部前端评审逐条列出来，标明处理结果，加上本版新功能的
自审，以及仍需你验证的部分。它同时是下次回归的基线。

核实结论：**21 条里 19 条属实，1 条判断错误，1 条需要真机验证。**

## 一、外部评审逐条

### 判断错误的一条

| # | 评审说法 | 结论 |
| --- | --- | --- |
| E1 | “整个应用是一个 8.5k 行的单 HTML 文件，建议拆模块 + esbuild” | **不成立**。源码是 13 个模块（`web/js/`，最大 `view-word.js` 约 1500 行），7521 行那个是 `tools/build.mjs` 拼出的离线产物。**不做 esbuild。** |

### 数据正确性

| # | 问题 | 处理 |
| --- | --- | --- |
| 1 | `runLines` / `runOverview` 回调直接写全局 `state.lineState`，跨词条串台 | **已修**：`reset()` 递增 `state.generation`，回调写 `state.*` 前比对；写词条自身的 `entry.lines` 照旧（那是用户付过钱的数据） |
| 1b | 请求从不取消，白烧 token | **已修**：`api` 全接口接受 `signal`，与超时 controller 合流；离开词条页 `leave()` 全部 abort；新增错误 kind `aborted`，回调完全忽略 |
| 2 | `slug()` 只保留 `[a-z0-9_]` → `pâte`/`pète`、`Essen`/`essen` 撞 id | **已修**：id 改为 `slug--<6位哈希>--语言--模型--解释语言`，哈希取 `word.normalize('NFC')` 且保留大小写；`slug` 也先归一 |
| 2b | 句子 id 只取前 6 个词 | **已修**：哈希取整句原文 |
| 2c | 同一个词用 Auto 与锁定语言查生成两个 id，重复计费 | **已修**：语言解析后重算最终 id 并 `location.replace`，两条合并为一条 |
| 3 | “清除星标”文案与行为不符，且留下空壳历史 | **已修**：不再删 payload；只清 starred 并清空单词本，文案改成实话 |
| 4 | `exportAll` 不含单词本，`importAll` 丢 `kind`/`reading` | **已修**：备份带 `wordbooks`；导入保留 `kind`/`reading`/`sourceLangArg`，按 id 合并而非覆盖 |
| 5 | 配额写满时 `saveEntry` 失败但 `upsertRow` 照跑，留下打不开的历史行 | **已修**：payload 写失败先剪最旧的未收藏条目重试一次；仍失败则**不写行**并向上返回失败，词条页显示 `Storage is full` |
| 6 | 意大利语与西班牙语的发音用英语音 | **已修**：两处发音映射补齐 `it-IT` / `es-ES` |
| 7 | 打开收藏夹就无上限并发识别、用户不知情就花钱 | **已修**：不再自动运行，用户点 `Identify 3 of N` 才跑；串行、每次最多 3 条、每会话每条一次 |

### 技术实现

| # | 问题 | 处理 |
| --- | --- | --- |
| 8 | 任何状态变化都整屏重建，下拉被关、光标丢失、候选面板被毁 | **部分已修**：卡片区包进 `#deep-region`，词条页在 `overviewState === 'ready'` 时只重绘卡片区，并抽出 `wireRegion()` 重绑区内监听器。未引入区块渲染框架（按决定不做） |
| 9 | 每次 hashchange 都滚回顶部 | **已修**：按路由记 `scrollY`，返回时恢复，新导航才滚顶 |
| 10 | 存储层每次全量读取并解析，收藏夹 O(n²) | **已修**：索引与单词本进内存缓存，写入走缓存；payload 按需读。附带修掉由此引入的别名 bug：`exportAll`/`snapshotEntry` 改为返回深拷贝 |
| 11 | 只有 429 重试；60 秒超时太长 | **已修**：5xx / network / timeout 也重试一次（带退避，aborted 永不重试）；`timeoutMs` 60000 → 45000（实测最慢一条 7.3s） |
| 12 | tab 是 `<button>`、行是 `<div>`，不能新标签打开或键盘聚焦 | **部分已修**：底部三个 tab 改成 `<a href="#/…">`。历史与收藏的行标题仍待改 |
| 13 | 交付物是手拼单文件，工程化不足 | **不改**：单文件是**产物**不是源码；`build.mjs` 有白名单、顺序校验与 16 项自检 |

## 四、债务清单（有意不做）

| 项 | 为什么不做 |
| --- | --- |
| IndexedDB 存储 | 需要把全部调用点 promise 化，属重写级改动；5 MB 配额对个人词典够用，且已有配额检测与剪枝 |
| 区块渲染框架 / 局部 diff | 只修了“会丢用户输入与位置”的痛点；整体重写视图层风险远大于收益 |
| esbuild / 打包器 | 源码已模块化，单文件是产物 |
| 卡片标题本地化 | `Senses · Sens` 是“英文类别 + 源语言术语”的学习术语，翻成第三种语言反而更乱 |
